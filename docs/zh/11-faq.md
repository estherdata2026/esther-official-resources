# 11. 常见问题与已知限制


**Q：选择"自动检测"识别出的方言不对？**
A：混合方言的 SQL 脚本可能被误判，手动指定方言更可靠。可通过 `GET /api/dialects` 确认可用方言列表。

**Q：动态 SQL（`EXECUTE IMMEDIATE` / `sp_executesql`）能分析吗？**
A：静态分析无法展开运行时才拼出的 SQL。Esther 会检测到动态 SQL 并给出 `DYNAMIC_SQL` 警告，相关血缘节点置信度标注为 30%，不会被静默丢弃。

**Q：分析页的结果刷新后没了？**
A：分析页是即席沙箱，不持久化。需要长期保存、跨对象溯源请使用元数据采集任务（第 5 章）。

**Q：采集任务的 SQL 脚本包为什么必须指定方言？**
A：整包脚本的自动检测容易误判，一旦误判会导致批量解析缺失、资产静默缺漏。因此脚本包来源强制显式指定数据库类型，运行时也会二次校验。

**已知限制**

| 限制 | 说明 |
|------|------|
| 溯源深度 | 无硬性上限（默认走到底）；超大图建议配合类型过滤 / 端点追溯收窄视图 |
| 自动布局层数 | 单图最多 12 层，超大图建议按资产粒度查看 |
| `POST /api/analyze` 无鉴权 | 请内网部署 |
| GOTO 静态不确定性 | 过程内 GOTO 跳过的 DML 以 `GOTO_UNCERTAINTY` 警告 + 保守标记呈现 |
| 杀软误报 | Nuitka 编译产物可能被个别杀软误报，请加白名单 |

财务人工核对到账后 1 个工作日内订单生效，license 自动生成。

支持增值税普票/专票，支付完成后可在控制台申请开票。

控制台 → License 管理 → 重置机器绑定，每自然月可自助重置 2 次。

不会。过期后仅停止付费功能，本地数据完整保留，续费后立即恢复。

**Q：支持哪些部署方式？**

Windows / Linux / Docker 三种交付形态，全离线运行，数据不出企业内网。
