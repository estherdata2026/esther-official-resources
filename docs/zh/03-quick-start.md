# 3. 快速上手：第一次血缘分析


打开浏览器进入系统后：

1. 在登录页输入管理员账号登录（默认账号见 [2.3](#23-运行数据与账号)）。
2. 在左侧导航点击 **数据血缘**，进入 SQL 血缘分析页。
   页面首次加载时会**自动运行一段演示 SQL** 并渲染血缘图谱——你打开就能看到效果。
3. 在 SQL 编辑器中粘贴自己的 SQL（支持多条语句、存储过程、CREATE 语句等）。
4. 在方言下拉框选择对应数据库；不确定时保持 **自动检测**。
5. 点击 **分析** 按钮（快捷键 `Ctrl + Enter`）。
6. 查看结果：
   - 顶部统计栏：**节点数 / 边数 / 警告数** 及识别出的方言；
   - **血缘图**标签页：交互式图谱，工具条支持方向 / 深度 / 类型过滤 / 端点追溯等血缘查询（见 [4.6](#46-图交互与血缘查询)）；
   - **表格**标签页：Excel 式血缘数据表，支持筛选、排序、分页与导出 CSV；
   - **JSON**标签页：原始分析结果，可直接对照 API 文档；
   - 底部警告面板：解析警告可点击定位到 SQL 对应位置。

> 提示：分析页是"即席分析沙箱"，结果不落库。要让血缘持久保存并支持跨对象溯源，请使用元数据采集任务（见第 5 章）。
