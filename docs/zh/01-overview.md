# 1. 产品概述


**Esther** 是一个企业级**数据血缘与数据智能平台**。它不仅解析 SQL 文本，还能直接读取 Kettle、SSIS、DataX、Informatica、dbt 等 ETL 工具的作业文件，自动提取**列级别**的数据流转关系——某张报表字段的数据从哪些表哪些列来、中间经历了什么计算与转换步骤、又流向了哪里——并以交互式血缘图谱呈现。在此基础上，Esther 还提供元数据资产目录、数据质量引擎、AI 智能体助手与 MCP Server，让血缘不只是"一张图"，而是可查询、可对话、可接入 AI 工作流的活数据。

### 1.1 解决什么问题

| 场景 | 没有血缘时 | 有了 Esther |
|------|-----------|------------|
| **变更影响分析** | 改一个底层表字段，不知道会炸哪些下游报表 | 在图上选中该列，一眼看到全部下游链路 |
| **数据治理** | 表、视图、存储过程的关系散落在成千上万行 SQL 里 | 自动解析 SQL，生成完整血缘图谱 |
| **合规审计 / 数据溯源** | 被问"这个对外字段的数据从哪来"时人工翻代码 | 上游溯源功能逐层回溯到数据源头 |
| **数仓迁移 / 重构评估** | 人工评估工作量，容易遗漏 | 基于血缘图统计受影响对象，量化评估 |
| **ETL 作业盘点 / 迁移** | 数百个 Kettle / SSIS 作业的逻辑藏在工具里，没人说得清全貌 | 上传作业文件，转换步骤与列级血缘一张图呈现 |
| **"问"数据 / AI 集成** | 每次都要打开页面翻菜单找答案 | 直接用自然语言问 AI 助手，或在 Claude Code、Cursor 中通过 MCP 查血缘 |

### 1.2 使用形态

- **Web UI** — 浏览器中粘贴 SQL 即时出图，交互式浏览血缘
- **REST API** — 提供完整的 OpenAPI/Swagger 文档，便于与自有系统集成
- **命令行 CLI** — 脚本化批量分析，输出 JSON 或表格
- **AI 助手与 MCP** — 平台内置 AI 智能问答与血缘诊断；MCP 端点可接入 Claude Code、Cursor 等 AI 客户端（见第 7 章）

### 1.3 典型能力一览

- 列级血缘：精确到字段，区分直传 / 转换 / 聚合 / 过滤 / 关联等 9 种边类型
- 30 种 SQL 方言（含 GaussDB），覆盖主流数据库与达梦、人大金仓等信创数据库，支持方言自动检测
- 存储过程深度解析：PL/SQL、PL/pgSQL、T-SQL、MySQL 存储过程，含变量、游标、控制流、触发器
- ETL 工具作业血缘：Kettle、SSIS、DataX、Informatica PowerCenter、dbt 作业文件直接解析为列级血缘
- AI 智能体助手：智能问答与血缘诊断，支持接入自定义大模型端点（OpenAI 兼容接口、DeepSeek、通义千问等）
- 内置 MCP Server：Claude Desktop、Cursor 等 AI 客户端可通过 MCP 直连查询血缘，支持访问令牌管理
- 数据质量引擎：质量规则绑定资产、定时调度、异步执行、Webhook 告警，支持行级采样与参考数据集核查
- 交互式血缘查询：方向 / 深度 / 类型过滤 / 端点追溯，表级与列级一键切换，选中即全路径高亮
- 血缘结果双视图：交互式图谱 + Excel 式数据表（筛选 / 排序 / 分页，导出 CSV）；图谱可导出 PNG，结果可查看 JSON
- 元数据采集任务：数据源与 SQL 脚本包双来源，差异合并自动增删改资产，运行日志与血缘快照
- 上游溯源 / 下游影响分析：基于图数据库的多跳遍历
