# 7. AI 助手与 MCP


Esther 内置 **AI 智能体助手**（付费模块）与 **MCP Server**，让"问数据"和"在 AI 工具里用血缘"成为可能。

### 7.1 前置：接入大模型（模型接入）

AI 问答依赖 chat 模型端点，首次使用前需配置：

1. 左侧导航进入 **模型接入**；
2. 点击 **新建**，填写模型名称、Base URL、API Key 与参数（支持任何 OpenAI 兼容接口，如 DeepSeek、通义千问、私有化部署模型）；
3. 点击 **测试** 验证连通性，并在 **能力绑定** 中将其绑定为 chat 模型；
4. 在 **助手** 开关中启用 AI 助手。

未配置模型时，AI 对话面板会提示"对话模型未配置"并引导跳转，平台既有功能不受影响。

### 7.2 AI 对话（智能问答）

点击界面中的 **AI 助手** 悬浮球打开对话面板：

- 用自然语言提问，例如"订单主表有哪些字段？负责人是谁？""最近的血缘分析都覆盖了哪些数据源？""最近的数据质量检查结果怎么样？"；
- 助手基于平台自身的结构化数据作答——资产目录、血缘分析、数据质量结果——回答支持 Markdown 与**引用来源**，可溯源；
- 回答中出现的血缘关系可**点击查看交互式血缘图**；
- 支持历史对话管理、复制回复等。

### 7.3 AI 血缘诊断

在数据血缘分析结果页点击 **AI 诊断**：

1. 先做**规则检查**（悬空引用 / 缺失嫌疑 / 低置信度等维度）；
2. 再由 AI 深度分析血缘并整理评审结论；
3. 输出 **AI 血缘诊断报告**：结论为"未发现血缘错误 / 发现疑似问题 / 无法判定"三种，并附问题清单与依据。

> AI 诊断结果由模型生成，仅供参考，请人工核对后再采纳。

### 7.4 MCP Server：让 AI 客户端直连

Esther 内置 MCP（Model Context Protocol）服务器，端点为 `http://<host>:8000/api/mcp`（streamable HTTP）。任何支持 streamable HTTP 的 MCP 客户端（Claude Code、Cursor 等）均可接入。

**第一步：创建 MCP API Token**

左侧导航进入 **MCP API Token** 页 → **新建 Token** → 命名（如"Claude Code（数据组）"）并选择有效期（30 / 90 / 365 天或永不过期）。Token 明文仅在创建时显示一次，请立即保存；不再使用时支持随时吊销。

**第二步：在 AI 客户端中接入**

以 Claude Code 为例，在其 MCP 设置中加入：

```json
{
  "mcpServers": {
    "esther": {
      "url": "http://<host>:8000/api/mcp",
      "headers": { "Authorization": "Bearer estm_..." }
    }
  }
}
```

**可用工具**

| 工具 | 说明 |
|------|------|
| `query_lineage` | 血缘查询：按分析 ID / 数据源 / 节点查询上下游，支持方向与深度 |
| `query_assets` | 资产目录检索 |
| `query_quality` | 数据质量结果查询 |
| `search_glossary` | 业务术语搜索 |
| `query_sql` | 平台内数据的受限查询 |
| `list_dialects` | 列出支持的 SQL 方言 |

> 安全与门禁：MCP 查询只针对平台自身数据（资产 / 血缘 / 质量 / 术语），不会直连你添加的数据源数据库；每次工具调用（含失败）均记录审计日志；MCP 受 license `assistant` 特性门禁。
