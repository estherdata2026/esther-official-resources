# 5. 元数据采集任务（持久血缘）


采集任务负责把外部元数据与 SQL 脚本沉淀进平台：**提取元数据**生成数据资产，**解析血缘**写入图数据库，并支持定时调度与差异合并。

### 5.1 两种采集来源（可任意组合，至少填其一）

| 来源 | 内容 | 说明 |
|------|------|------|
| **数据源** | 已在"数据源"页配置的数据库连接 | 全量提取表 / 列 / 视图 / 物化视图 / 过程 / 函数 / 触发器 / 序列 / 同义词 / 包 / 索引 / 约束 / 分区等对象，写入数据资产库 |
| **SQL 脚本包（zip）** | `.sql` / `.ddl` / `.txt` 脚本压缩包 | 解析其中的 DDL 与 DML：`CREATE TABLE` 沉淀为数据资产，全部语句提取列级血缘。单包 ≤ 20MB、≤ 500 个文件、解压总量 ≤ 100MB；单文件解析失败不中断整批，自动尝试多种文件编码 |

**同时选择时**：先提取数据源的最新元数据，再基于它解析脚本血缘（脚本中的表可对上数据源真实结构，`SELECT *` 展开与列消歧更准）。

### 5.2 创建与编辑任务

在"采集任务"页点击创建，填写：

- **名称**（必填）；
- **数据源**：选择已配置的连接；
- **SQL 脚本包**：上传 zip 压缩包；
- **数据库方言**：脚本包来源**必选，且不允许"自动检测"**——整包脚本的自动检测容易误判，会导致批量解析缺失、资产静默缺漏，因此必须明确指定脚本所属的数据库类型；
- **调度**：手动 / 每小时 / 每天午夜 / 每天凌晨 2 点 / 每周日凌晨 3 点（cron 预设）；
- **描述**。

任务创建后可随时**编辑**：更换数据源、重新上传脚本包、修改方言 / 调度 / 名称 / 描述。

### 5.3 运行与调度

- **立即运行**：任务卡片或详情页点击"立即运行"；
- **定时调度**：按预设 cron 周期自动运行（调度器每分钟扫描到期任务）；
- 同一数据源的采集任务**互斥执行**：一个任务运行中时，指向同一数据源的其他任务会提示"稍后再试"。

### 5.4 差异合并：无变更不产生新版本

每次运行会对比本次提取结果与资产库的内容指纹（对象名 → 内容摘要）：

- **无差异**：本次运行标记"**无变更**"，不产生新的资产版本与血缘快照（血缘仍会"删旧重建"，保证与最新元数据一致）；
- **有差异**：自动**删除源上已消失的资产**（源库删表后资产不会残留）→ 建立元数据快照 → 重新解析血缘 → 建立血缘快照；
- 运行历史以 **`+N ~N -M`**（新增 / 更新 / 删除）展示变更摘要。

### 5.5 运行历史与日志

任务详情页的"执行历史"逐条记录：

- **资产变更**：`+N ~N -M` 或"无变更"；
- **血缘产出**：本次执行新增的 `N 节点 · M 边`；
- **错误徽标 `⚠ N`**：本次运行中解析失败的数量，悬停显示错误摘要（最多 20 条）——成功的运行也可能有部分文件解析失败；
- **查看日志**：弹窗查看本次运行的完整日志（含各文件解析报错原文），可**下载 `.log` 文件**用于反馈定位。

### 5.6 孤儿表归入

血缘中出现、但资产库中不存在的表（可能拼写有误、来自动态 SQL 或尚未采集）会在运行历史中以 **`◇ N`** 标记。展开后可逐张或一键"**归入资产库**"，确认后即追加为正式资产。

### 5.7 视图与序列的处理

- **视图入资产**：`CREATE VIEW` / `CREATE MATERIALIZED VIEW`（含脚本包内语句）会注册为**视图资产**并保存视图定义文本——血缘解析时按定义逐层穿透展开（视图 → 视图 → 表），`SELECT *` 也能按视图输出列正确展开；
- **序列（SEQUENCE）**：序列是计数器而非数据流对象，系统按独立类型节点记录其属性（起始值 / 步长 / 上下限等），不产生虚假的表卡片，也不参与列级血缘。

### 5.8 资产目录与资产树

- 资产按 **库 → 模式 → 对象** 层级组织；脚本包中缺省库 / 模式名的对象自动归入 `default` 命名空间，保证资产树不断链；
- 资产详情页的"**结构**"列表展示下级对象（表 → 列，模式 → 表 / 视图），可逐层点击下钻；
- 分析页元数据树中的**表 / 视图（含物化视图）/ 列**支持右键直接发起血缘查询（下游 / 上游 / 双向 / 端点追溯），与血缘图右键菜单同一套动作。
